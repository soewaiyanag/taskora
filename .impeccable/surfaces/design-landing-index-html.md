# Surface: marketing landing page

Mode: Persuade. Light first; follows the system theme.
Audience: portfolio reviewers (recruiters, hiring managers, engineers) first, small teams second.
Action: "Try the demo" (sample workspace, no signup); secondary: the code on GitHub.
Proof: the product itself, animated live. No logos, user counts, ratings, percentages or testimonials exist, and none are invented.
Reference: ClickUp's homepage structure (hero with one free action and a reassurance line, interactive product demo, feature switcher, repeated CTA), without its claims, logos or "replace all software" rhetoric. Taskora's angle is calm, not everything.

## Direction contract

FORM: Two screens, one board (seed:f784bc489facb3b9), dealt structure chosen by the user, inside the established Quiet Planning Wall world.

THESIS: Prove "your team sees it at once" in one picture: two teammates' screens of the same board, where a move on one lands on the other. Refuses the category's screenshot-plus-feature-grid page and the claims-and-logos rhetoric.

OWN-WORLD: DESIGN.md unchanged: stone wall ground, white paper windows and cards, graphite shell for sidebars and the closing band, owner inks only on things that belong to a teammate (Mai ochre, Jonas harbour), Archivo's wide cut for headlines and the wordmark (this page's extension of the Two Titles Rule), Archivo at normal width for UI and copy, Martian Mono only for task codes, keys and code samples. Nav carries the Flagged T lockup (2026-11-16, user-chosen).

FIRST VIEWPORT: slim nav with the Flagged T lockup; wide headline "Move a card. Your team sees it at once."; lede, Try the demo with "Sample workspace · no signup", GitHub link; Mai's and Jonas's app windows overlapping on the wall, playing the sync loop; a visible pause control and a "Sample data" note.

SIGNATURE: The sync loop. Mai's cursor lifts WEB-142 and carries it to In progress; it lands on Jonas's board with her ink outline and a toast. The windows trade places and Jonas moves WEB-138 to Done; it lands on Mai's screen and sinks into Done. The loop never resets (2026-11-16): each round Mai takes the next To do card, Jonas finishes the oldest In progress card, the Done count keeps climbing and a new task arrives in To do. A remote move shows the mover's ink and name first, then glides without bounce.

STORY: hook and action → "How it works" switcher (owner lens, instant moves, live presence, ⌘K), each tab animating one window → "Calm by default" three statements → "How it's built" architecture and type chain for engineers → graphite closing band with the action again → credit footer.

RISK: shrunken app windows on phones; the stage scales as one picture with a caption, and the loop pauses offscreen and under reduced motion.
